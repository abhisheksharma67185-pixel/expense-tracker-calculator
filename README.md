# Cash Expense Tracker

Terminal app for tracking daily expenses:
- Add amount + category (stored as dicts)
- View all expenses listed
- Calculate total spending instantly
- Clean menu interface

**Skills:** Dictionaries, list comprehensions, `sum()`, data aggregation

Run: `python expense_tracker.py`
